### Средняя сложность №4

В файле `task4.py` реализован класс `Figure`, описывающий круг.

Конструктор `__init__()` принимает радиус и сохраняет его в атрибуте
`radius`. При нулевом или отрицательном радиусе вызывается исключение
`ValueError` с сообщением об ошибке.

Для вычислений созданы два метода:

- `area()` возвращает площадь круга по формуле `πr²`;
- `perimeter()` возвращает длину окружности по формуле `2πr`.

Значение числа π берётся из модуля `math`. В демонстрации создаётся
объект с радиусом 5.5, после чего вызываются оба метода.
Результаты выводятся с двумя знаками после десятичной точки.

Результат запуска:

```text
Площадь круга: 95.03
Длина окружности: 34.56
```

### Средняя сложность №6

В файле `task6.py` реализован класс `TextAnalyzer` со статическим
методом `count_vowels()`.

Метод объявлен с декоратором `@staticmethod`. Он не принимает `self`
и не использует состояние объекта, поэтому вызывается непосредственно
через класс:

```python
TextAnalyzer.count_vowels("Привет, мир!")
```

Перед подсчётом проверяется тип аргумента. Если передана не строка,
вызывается исключение `TypeError`.

Для поиска гласных используется набор русских букв `аеёиоуыэюя`
и английских букв `aeiou`. Строка преобразуется в нижний регистр,
после чего каждый символ проверяется на принадлежность этому набору.
Метод возвращает количество найденных гласных.

Буква `y` не учитывается: её роль в английском языке зависит от слова.
В программе используется фиксированный набор пяти английских гласных.

В код добавлены примеры русской, английской и смешанной строк,
строка с буквами верхнего регистра, строка без гласных и пустая строка.
Все примеры заданы в коде без пользовательского ввода.

Результат запуска:

```text
'Привет, мир!': гласных - 3
'Hello, world!': гласных - 3
'ООП на Python': гласных - 4
'АЕЁИОУЫЭЮЯ AEIOU': гласных - 15
'бвгд 123!': гласных - 0
'': гласных - 0
```

### Средняя сложность №10

В файле `task10.py` реализован класс `PowerIterator`.

Конструктор принимает параметры `limit` и `power`. При использовании
целого неотрицательного `limit` итератор возвращает степени чисел
от 1 до `limit` включительно. Степень по умолчанию равна 2.
Отрицательный `limit` отклоняется с исключением `ValueError`.

Текущее число хранится в атрибуте `current`, начальное значение - 1.

Протокол итерации реализован двумя методами:

- `__iter__()` возвращает сам объект-итератор;
- `__next__()` вычисляет очередную степень и увеличивает счётчик.

После достижения установленного лимита метод `__next__()` вызывает
`StopIteration`, что завершает цикл `for`. Состояние итератора
при вызове `__iter__()` не сбрасывается. При `limit=0`
последовательность пустая.

В демонстрации выводятся квадраты чисел от 1 до 5.

Результат запуска:

```text
Квадраты чисел от 1 до 5:
1
4
9
16
25
```

### Повышенная сложность №5

В файле `task5pov.py` реализован класс `JsonSerializer`
для сохранения и загрузки словарей в формате JSON.

Конструктор принимает путь к файлу и сохраняет его как объект `Path`.

Метод `save_to_json()` проверяет, что переданные данные являются
словарём, и преобразует их в JSON с помощью `json.dumps()`.

При преобразовании используются параметры:

- `ensure_ascii=False` - русские буквы сохраняются без экранирования;
- `indent=4` - содержимое форматируется с отступами;
- `allow_nan=False` - запрещается сохранение `NaN` и бесконечности.

Словарь должен содержать JSON-совместимые данные. Преобразование
в JSON выполняется до открытия файла на запись, поэтому ошибка
сериализации не стирает ранее сохранённое содержимое.
Запись выполняется в кодировке UTF-8.

Метод `load_from_json()` читает данные с помощью `json.load()`
и проверяет, что результат является словарём. Если файл отсутствует,
возникает `FileNotFoundError`; при повреждённом JSON —
`JSONDecodeError`; при другом типе корневого значения — `ValueError`.

В демонстрации используется следующий словарь:

```python
sample_data = {
    "student": "Воробьева Дарья Сергеевна",
    "group": 221341,
    "lab": 3,
}
```

Программа сохраняет его в JSON, читает обратно и сравнивает
полученные данные с исходными.

Для демонстрации используется `TemporaryDirectory`.
Временная папка вместе с JSON-файлом автоматически удаляется
при выходе из блока `with`, в том числе при возникновении ошибки.
Сам класс не удаляет файлы: очистка относится только к демонстрации.

В блоке запуска обрабатываются ожидаемые ошибки файловых операций,
типов и значений с помощью `except (OSError, TypeError, ValueError)`.

Результат запуска:

```text
Данные успешно сохранены в JSON.
Десериализованные данные: {'student': 'Воробьева Дарья Сергеевна', 'group': 221341, 'lab': 3}
Данные совпадают: True
```

Пример данных хранится в коде. Временный файл `temp_data.json`
добавлен в `.gitignore` и не предназначен для хранения в репозитории.

### Повышенная сложность №9

В файле `task9pov.py` реализован абстрактный базовый класс `Employee`
с использованием модуля `abc`.

Класс наследуется от `ABC`, а метод `calculate_salary()` помечен
декоратором `@abstractmethod`. Создать экземпляр `Employee` нельзя:
для создания объекта необходимо реализовать абстрактный метод
в дочернем классе.

Класс `HourlyEmployee` наследуется от `Employee`.
Через `super().__init__(name)` вызывается конструктор базового класса,
который сохраняет имя сотрудника.

Конструктор дочернего класса принимает количество отработанных часов
и часовую ставку. Отрицательные значения отклоняются с исключением
`ValueError`.

Метод `calculate_salary()` реализован в дочернем классе
и возвращает произведение часов и ставки. Метод `get_info()`
базового класса вызывает эту реализацию и формирует строку
с именем сотрудника и зарплатой.

В демонстрации создаётся сотрудник, отработавший 40 часов
со ставкой 850.50 рубля в час.

Результат запуска:

```text
Сотрудник: Дарья Сергеевна, Зарплата: 34020.00 руб.
```

В коде также оставлен закомментированный пример создания `Employee`.
При его выполнении возникнет `TypeError`, поскольку класс абстрактный.
